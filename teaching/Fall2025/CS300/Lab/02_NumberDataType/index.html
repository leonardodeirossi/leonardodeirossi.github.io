JavaScript cookbook - Number data type

Version: 2025/09a (2025-09-14 12:08:00)

In JavaScript, all numeric values – whether integers or decimals – belong to the same data type: number. There is no separate type for integers. This makes arithmetic simple and consistent across your code.

Examples of Numbers

Value Description
42 Integer number
3.14 Floating-point (decimal) number
-7 Negative number
Infinity Special value representing infinity
NaN “Not-a-Number” – result of invalid math operations

Using Numbers

You can do arithmetic with numbers directly: 

let a = 10;
let b = 3;
let sum = a + b;       // 13
let quotient = a / b;  // 3.333...

And when the value we assign is not a number?

When we work with input from the user, sometimes the value we get is not in the correct type. To mitigate the issue, JavaScript provides some functions to convert a generic variable to a number.
