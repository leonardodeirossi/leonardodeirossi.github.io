JavaScript cookbook - Variables and data types

Version: 2025/09a (2025-09-14 12:08:00)

In JavaScript, variables are used to store data. You can declare a variable, give it a name, and assign it a value. Variables make your code reusable and easier to maintain.

Declaring Variables

JavaScript offers three main ways to declare variables:

  • var – old way, function-scoped.
  • let – block-scoped, recommended for variables that may change.
  • const – block-scoped, for constants that cannot be reassigned.

Example:

var name = "Alice";
let age = 25;
const country = "Italy";

Variable Types

Variables in JavaScript can hold different types of data. Common types include:

Type Example Description
String "Hello World" Text inside quotes.
Number 42 Any numeric value.
Boolean true or false Logical values.
Array [1, 2, 3] List of values.
Object {name: "Alice", age: 25} Key-value pairs.

Assigning Values

You can assign a value to a variable at declaration or later in your code: 

let color;          // declared but not assigned
color = "blue";     // now assigned
const pi = 3.14159; // assigned immediately
